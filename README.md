# Giga Corp Org Chart

An interactive organization chart built with Vue.js, D3.js, and Tailwind CSS.

## Features

- Visualizes company hierarchy in a tree layout
- Expand and collapse nodes
- Zoom and pan support
- Shows salary, total descendants, IC cost, management cost, and total cost

## Tech Stack

- Vue 3 (Composition API)
- D3.js
- Tailwind CSS
- PapaParse (for CSV parsing)
